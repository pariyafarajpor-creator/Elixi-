# Exir — ابزار آموزشی امنیت حساب‌ها

خلاصه
- Exir یک پروژهٔ آموزشی و دفاعی است که هدفش افزایش آگاهی دربارهٔ امنیت حساب‌های آنلاین (مثل جیمیل و اینستاگرام) و ارائهٔ چک‌لیست‌ها، راهنماها و تمرین‌های قانونی برای محافظت و بازیابی حساب‌ها است. این پروژه هرگونه ابزار یا راهنمایی برای دسترسی غیرمجاز را منع می‌کند.

هشدار مهم (قوانین و اخلاق)
- استفاده از این پروژه برای نفوذ، هک یا دسترسی غیرمجاز به حساب‌های دیگران ممنوع و غیرقانونی است.
- هرگونه آزمایش نفوذ تنها در محیط‌های آزمایشی و با مجوز صریح مالک سیستم مجاز است.
- نویسنده و مشارکت‌کنندگان مسئول استفادهٔ غیرقانونی کاربران نیستند.

ویژگی‌ها
- چک‌لیست قدم‌به‌قدم برای تقویت امنیت حساب‌ها
- راهنمای فعال‌سازی و مدیریت تایید دومرحله‌ای (2FA)
- نکات و نمونه‌هایی برای شناسایی و جلوگیری از فیشینگ
- راهنمای بازیابی حساب و تماس با پشتیبانی سرویس‌ها
- منابع آموزشی و لینک به مراجع رسمی برای مطالعهٔ بیشتر
- تمرین‌های پیشنهادی برای محیط‌های ایزوله و قانونی

نمونهٔ چک‌لیست امنیتی (خلاصه)
1. رمز عبور
   - از رمز عبور قوی و یکتا استفاده کنید.
   - از Password Manager معتبر استفاده کنید.
2. تایید دومرحله‌ای (2FA)
   - 2FA را با اپلیکیشن احراز هویت (مثل Google Authenticator یا Authy) فعال کنید.
   - در صورت امکان از کلید سخت‌افزاری (FIDO2) استفاده کنید.
3. ایمیل بازیابی و شماره تلفن
   - ایمیل بازیابی و شماره تلفن را به‌روز نگه‌دارید.
   - بررسی کنید چه دستگاه‌هایی دسترسی دارند و جلسات فعال را از تنظیمات سرویس بررسی کنید.
4. تشخیص فیشینگ
   - لینک‌ها را قبل از کلیک بررسی کنید.
   - ایمیل‌ها و پیام‌های مشکوک را گزارش کنید.
   - از باز کردن پیوست‌های ناشناس خودداری کنید.
5. بازیابی حساب
   - اطلاعات بازیابی (پرسش‌های امنیتی و ایمیل‌های جایگزین) را امن نگه دارید.
   - مراحل رسمی بازیابی سرویس‌دهنده (مثلاً Google یا Instagram) را دنبال کنید.

نصب و اجرا (نمونه)
- پیش‌نیازها: Python 3.x (برای بخش‌های اسکریپتی) یا هر پشته‌ای که پروژه استفاده می‌کند.
- نصب وابستگی‌ها (نمونه):
  - pip install -r requirements.txt
- اجرا
  - توضیح مختصر نحوهٔ اجرای اسکریپت‌ها یا نمایش صفحات مستندات (در صورت وجود)

نحوهٔ مشارکت
- مشارکت‌کنندگان خوش‌آمدند. لطفاً قبل از ارسال کد یا محتوا:
  1. اطمینان حاصل کنید محتوای ارسالی مطابق قوانین محل شماست.
  2. در درخواست‌های pull توضیح دهید که تغییرات چه‌چیزهایی را بهبود می‌بخشد (مثلاً اصلاح چک‌لیست، افزودن مرجع رسمی).
  3. مسائل مربوط به امنیت را از طریق issue یا ایمیل اعلام کنید؛ در صورت نیاز به افشای آسیب‌پذیری، از روش‌های امن و خصوصی استفاده کنید.
